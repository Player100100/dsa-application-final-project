# 模块规格 · 图搜索 Dijkstra / A*

文件：[03_代码/ds/astar.py](../03_代码/ds/astar.py)
对应任务书：图结构 → 路径规划与拓扑建模 → **基础级 + 进阶级**

## 目标

把栅格地图当成八邻域网格图，实现 Dijkstra 与 A*；A* 在同一框架下
只换启发式，保证两者可直接对拍、对比展开节点数。

## 数据结构与复杂度

| 结构 | 用途 |
|---|---|
| `heapq` 二叉堆 | 开放集，按 `f = g + h` 取最小；Dijkstra 时 `h ≡ 0` |
| `dict` g_score | 到各节点的当前最优代价 |
| `dict` parent | 回溯路径 |
| `set` closed | 已展开节点 |

- 时间：O(E log V)，E ≤ 8V；A* 的有效 E 由启发式质量决定；
- 空间：O(V)，V = width × height。

## 接口

```python
res = astar(grid, start_cell, goal_cell, blocked=mask)   # PathResult
res.found / res.path / res.cost / res.expanded / res.reason
res2 = dijkstra(...)                                      # 同一签名
```

`blocked` 是布尔列表（`True` = 不可走），由 `grid.inflated_mask()` 生成；
省略则内部自动生成。允许起点落在膨胀带内（贴墙时能开出去），终点不可。

## 关键决策

1. **同一内核两种启发式**：`heuristic="octile"` 或 `"zero"`，避免两份代码行为漂移；
2. octile 启发式在八邻域、单位代价下是**一致**的 → A* 最优且展开节点 ≤ Dijkstra
   （单测断言）；
3. **禁止斜穿障碍拐角**：对角移动要求两个正交邻格都可走，避免路径擦着墙角；
4. 路径平滑只删共线点，不做捷径重连，保持可解释；
5. 规划失败时，演示层按 0.25 → 0.15 → 0 逐级降膨胀重试——车已贴墙时唯一可行解。

## 验收

- 单测：`tests/test_astar.py`（13 个：直线、终点阻挡、越界、留门墙、
  无解、禁止切角、对角、与 Dijkstra 同代价且展开更少、未知区策略、膨胀、平滑、
  起点邻域解阻 ×2）；
- 基准：160×160、18% 障碍、5 个种子 —— A* 34.0 ms / 6733 节点，
  Dijkstra 86.4 ms / 21121 节点，**A* 展开 31.9%**，路径代价完全相同；
- 实战：mock 160×160 图，单次 A*（296 节点）1.9 ms。

## 局限与下一步

- 只有静态重规划（0.8 s 一次），不是 D* Lite；动态障碍目前靠局部减速/绕行；
- 未知区默认当可走（乐观规划），贴近未知边界时依赖安全层兜底；
- 网格图不考虑车体朝向约束（差速/麦轮可原地转，暂不构成问题）。

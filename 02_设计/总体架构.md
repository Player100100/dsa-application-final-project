# 总体架构

## 1. 分层

```text
┌────────────────────────────────────────────────────────────┐
│ 演示/实验层   demo/nav_demo.py   demo/bench.py             │
├────────────────────────────────────────────────────────────┤
│ 算法层        ds/ring_buffer   ds/grid_map   ds/mapping    │
│               ds/kdtree        ds/astar                    │
├────────────────────────────────────────────────────────────┤
│ 适配层        robot_io.py（唯一 import rosmaster_client 处）│
├────────────────────────────────────────────────────────────┤
│ 外部          rosbridge ── 仿真/真车；mock_rosbridge（本机）│
└────────────────────────────────────────────────────────────┘
```

依赖方向严格向下；`ds/` 不 import `robot_io`，可脱离机器人单测。

## 2. 主循环数据流（10 Hz）

```text
/scan ──► RingBuffer(10)          只做缓存与丢帧统计
   │
   └──► ScanMapper.update(frame, odom)
             │  射线命中/穿过计数
             ▼
        GridMap（计数 → -1/0/100）
             │  每 0.8 s
             ▼
   inflated_mask ──► A* ──► smooth_path ──► 纯追踪 ──► /cmd_vel（每 0.1 s）
             ▲
/scan ──► 车体系点 ──► KDTree ──► 簇 ──► 近障减速（每 0.5 s）
```

## 3. 坐标与单位

| 量 | 约定 |
|---|---|
| 车体系 | +x 车头、+y 车左、逆时针 +yaw |
| odom | 起点为原点，位姿由轮式里程计给出（会漂） |
| 地图 | `(0,0)` 左下、x 列 y 行、格心 `origin+(cell+0.5)*res` |
| 角度 | 弧度；写入地图前用 `(a+π) mod 2π − π` 归一 |

雷达角 → 车体角：`bearing = angle_at(i) + laser_offset_yaw`，其中 offset 来自
`get_transform("base_link","laser_link")`，标准车为 +π。**不写死。**

## 4. 时间预算（mock 实测，1080 束 / 160×160 图）

| 步骤 | 单次耗时 | 频率 | 说明 |
|---|---:|---|---|
| `ScanMapper.update` | 4.3 ms | 每帧（~10 Hz） | stride=4，270 条射线 |
| `build_grid` | 2.0 ms | 0.8 s | 全图计数 → 三值 |
| `inflated_mask(0.25)` | 4.9 ms | 0.8 s | 半径 5 格 |
| A*（160×160） | 1.9 ms（296 节点） | 0.8 s | 同图 Dijkstra 52 ms / 9986 节点 |
| KD-Tree 聚类 | ~15 ms | 0.5 s | 270 点，stride=6 |

主循环 100 ms 周期内，最坏情况（建图 + 聚类同帧）约 25 ms，余量充足。
真车 `/scan` 仅 6.5 Hz，实际更宽松；瓶颈会转移到网络延迟（~143 ms）。

## 5. 失败与降级

| 情形 | 行为 |
|---|---|
| 无新 `/scan` | 跳过该拍，继续发上一拍速度（看门狗兜底） |
| 无 `/odom` | 不建图、不发速度，等待 |
| A* 无解 | 膨胀 0.25 → 0.15 → 0 逐级重试；仍无解则原地探索 |
| 车头 < 0.35 m | 停车并向空间大的一侧转（0.8 s 方向保持） |
| 障碍簇 < 0.65 m | 只减速 50%，不硬停 |
| 查不到坐标变换 | 启动时报错退出，不猜安装参数 |

## 6. 扩展点

- **动态障碍**：现有 `cluster_info` 可升级为“簇跟踪”（按质心关联前后帧），
  对速度非零的簇做局部绕行或触发重规划；
- **D* Lite**：`astar.py` 的 `PathResult` 与 `blocked` 接口可复用；
- **多层地图/广义表**：`GridMap` 之上再包一层楼层索引，不改进阶接口；
- **外部排序/日志**：与机器人解耦，单独模块，不影响主循环。

## 7. 明确不做

- SLAM / 回环检测 / 全局定位：只用里程计 + 局部地图，误差写进报告；
- 多传感器融合：IMU 仅保留接口，未参与姿态估计；
- 通用导航栈（Nav2 等）：本课程要的是自己实现数据结构与算法。

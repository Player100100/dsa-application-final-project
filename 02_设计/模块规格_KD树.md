# 模块规格 · KD-Tree（树）

文件：[03_代码/ds/kdtree.py](../03_代码/ds/kdtree.py)
对应任务书：树与二叉树 → 决策与空间索引 → **进阶级**

## 目标

给激光点云建空间索引，支持最近邻 / K 近邻 / 半径查询，并用半径查询做
欧氏距离聚类，把点云变成“障碍物簇”。

## 数据结构

二叉平衡树：每层用 `depth % dim` 轴、取中位数切分，左右子树递归。

| 操作 | 平均复杂度 | 说明 |
|---|---|---|
| 建树 | O(n log n) | 每层排序；n 帧内点数量级 10²–10³ |
| `nearest` / `knn` | O(log n) | K 近邻用最大堆维护候选 |
| `range_query` | O(log n + k) | 半径查询，剪枝用轴距平方 |
| `radius_clusters` | O(n log n + 邻域边数) | BFS 连通分量，O(n) 内存 |

## 接口

```python
tree = KDTree(points)                  # points: [(x, y), ...]
tree.nearest((0, 0))                   # 下标
tree.knn((0, 0), k=5)                  # [(距离, 下标), ...]
tree.range_query((0, 0), 0.5)          # [下标, ...]
tree.radius_clusters(0.2, min_points=3)  # [[下标...], ...]
```

## 关键决策

1. **静态树**：一帧点云建一次、用完即弃；不做插入/删除，避免复杂化。
2. 轴选择用轮换而非方差最大：实现简单，点云分布近似各向同性，实测够用。
3. 聚类用“半径连通”而非 DBSCAN：任务要的是“欧氏距离聚类”，
   连通分量语义直观；`min_points` 用来过滤孤立噪点。
4. **不依赖 numpy**：纯 Python 列表，验收环境零依赖。

## 验证

- 单测：`tests/test_kdtree.py`（7 个：KNN/最近邻与暴力对拍、半径查询、
  空树、两团聚类、min_points 过滤）；
- 基准：`demo/bench.py` 5000 点 / 200 次 k=5 查询，KD-Tree 8.8 ms vs
  暴力 973.3 ms（**111.0×**）；聚类 1200 点约 **1.5×**（见下）。

## 性能说明（要如实写进报告）

KNN 加速非常明显，但**聚类加速比只有约 1.4×**：每个点都要做一次半径查询，
Python 的递归/函数调用常数吃掉了大部分算法优势。这是“算法复杂度好 ≠
Python 实测快”的典型例子。若报告需要更强的聚类性能，可改用规则网格哈希
（但不属于本任务要求）；当前保留 KD-Tree，并在报告中解释差距。

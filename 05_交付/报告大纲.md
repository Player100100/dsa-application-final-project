# 书面报告大纲

> 任务书要求：书面报告 + 程序清单 + 测试视频。
> 本大纲按“选型 → 实现 → 验证 → 差异 → 优化”组织，对应 PBL 三层闭环。

## 封面与摘要（1 页）

- 题目：基于数据结构自实现的机器人定点/动态避障导航
- 一句话结论（含关键数字）：如“mock 三目标 100% 到达；A* 展开节点为 Dijkstra 的 31.9%”
- 小组成员与分工（对应 `01_规划/冲刺路线.md` §6）

## 1. 问题与任务分解（1–2 页）

- 任务书三层框架与本组选题
- 为什么选线性表/数组/树/图四条线（附依赖关系图）
- 明确不做的章节与理由（栈/队列/串/查找/排序）
- 分级目标：基础级/进阶级各做到哪；挑战级是否尝试

## 2. 数据结构选型与设计（3–4 页）

每模块一小节，统一结构：

| 小节 | 必写内容 |
|---|---|
| 2.1 环形缓冲 | 为什么定长顺序表；O(1) 覆盖；丢帧统计的用途 |
| 2.2 占据栅格 | 行主序一维数组；计数→三值规则；Bresenham 射线；trinary 落盘契约 |
| 2.3 KD-Tree | 中位数切分；KNN 最大堆；半径查询剪枝；连通分量聚类 |
| 2.4 Dijkstra/A* | 同一内核两种启发式；octile 一致性；禁止切角；复杂度 |

每节必须给：接口签名、复杂度表、关键代码片段（≤20 行）、与替代方案的比较。

## 3. 实现（2 页）

- 分层图（`ds/` / `robot_io` / `demo`）
- 10 Hz 主循环伪代码
- 时间预算表（建图 4.3 ms、A* 1.9 ms 等，注明 mock 环境）
- 失败降级表（膨胀重试、硬停阈值、无路径探索）

## 4. 仿真验证（2–3 页）

- 环境：mock 与课程仿真分别说明（帧率、延迟、场景尺寸）
- 单测：40 个用例覆盖哪些边界
- 基准表：A* vs Dijkstra、KD-Tree vs 暴力、聚类
- 导航结果：目标点 × 次数 × 到达率 × 用时 × 路径长度 × 重规划次数
- **必须放**：最终栅格地图截图 + 路径叠加图

## 5. 实物验证（2 页，如有）

- 真车环境、场地、速度限制
- 与仿真相同的目标点与指标表
- 现场问题记录（打滑、延迟、通信中断）

## 6. Sim2Real Gap 分析（2 页）

- 三环境对比表（`01_规划/冲刺路线.md` §5 的表）
- 差异归因：感知 / 执行 / 算法 / 环境四类
- 至少一个完整闭环案例：现象 → 假设 → 修改 → 重跑 → 数据变化
- 未解决差异与可能原因

## 7. 优化与结论（1 页）

- 优化前后对比（参数、成功率、用时）
- 数据结构层面的收获（何时数组优于树、何时 KD-Tree 不值得）
- 局限与展望（D* Lite、簇跟踪、SLAM）

## 附录

- A. 程序清单与运行说明（指向 `03_代码/README.md`）
- B. 实验记录索引（`04_实验/` 全部文件）
- C. 复现命令与环境版本
- D. 组内评审记录

## 写作纪律

1. 每个数字带出处（实验文件名 / 表号）；
2. mock、合成、仿真、真车四类数据不混表；
3. “更快/更稳”必须给前后对比；
4. 失败与未完成如实写，写清止损理由——比粉饰更加分。

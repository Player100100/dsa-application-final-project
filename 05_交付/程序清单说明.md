## 运行

```bash
pip install rosmaster_client-0.3.0-py3-none-any.whl
cd 03_代码
python -m unittest discover -s tests -t .
python demo/bench.py --save
python demo/nav_demo.py --ip mock --goal 2 2
python demo/nav_demo.py --ip <IP> --goal 1.5 0.0      # 仿真/真车
```
